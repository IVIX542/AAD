6. Pro Tips

🚀 Múltiples XML

No sobrescribas siempre el mismo archivo. Crea hibernate-juegos.cfg.xml y hibernate-escuela.cfg.xml y cárgalos en Java según necesites.

🧹 Limpieza

Si Eclipse muestra errores rojos pero el código está bien, ve a Project -> Clean... para forzar una recompilación.

🛠️ HibernateUtil

Usa siempre una clase Singleton auxiliar para crear la SessionFactory una sola vez al inicio de la app.
